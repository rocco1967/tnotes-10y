TNotes-10Y

A CatBoost-based directional model for 10-Year US Treasury Note Futures (ZN=F)

Overview

TNotes-10Y is a quantitative research project designed to estimate the five-session forward direction of 10-Year US Treasury Note Futures. The model uses historical price and volatility features and a CatBoost classification algorithm.

The project combines historical out-of-sample evaluation with a daily paper-trading signal.
